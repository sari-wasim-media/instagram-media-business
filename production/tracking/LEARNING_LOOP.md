# Learning loop — how Agile Revival measures and adapts

**Status: ACTIVE — delegated production decision under Agile Revival (founder decision, 2026-10-08).**
Replaces the frozen-experiment analysis for day-to-day decisions. The 84-post methodology in
`experiment/` is historical.

## One row per post — `agile_posts.csv`

Filled at publish (account, `publish_utc`, format, category C1–C4 or a named adjacent angle, angle, topic,
hook, files, audio, sources, asset IDs), then at each snapshot (one row per post, latest snapshot wins; earlier
reads go in `notes`): Reach, Views, non-follower %, likes, comments, saves, shares/sends, profile visits,
follows, average watch time (Reels), Story reach and sticker taps, and whether Account Status was still
green. **Reach is the denominator** for every rate; Views are recorded but never used as one.

## When to read

| Snapshot | Why |
|---|---|
| **~48 h** | Early read: did distribution start (non-follower %, Reach), did the hook hold (avg watch time) |
| **7 d** | The comparable read used for decisions |
| Weekly review | Every Monday: Account Status on both accounts (all five categories), the week's rows, and the next week's topics |

## How evidence changes the plan

- Compare posts on **rates per Reach** (saves, shares/sends, comments, profile visits, follows) and on
  non-follower share — medians once there are ≥ 5 posts in a group, raw values before that, and say which.
- Double down on what wins **on both accounts**; treat a one-account result as account-specific.
- A breakout is a signal to make more of that *kind* of post — never a repost of the same file.
- Change one thing at a time where possible (hook style, format, category, posting time) so the read stays
  attributable; note the change in the row.
- The default publish time is **16:00 UTC**; it moves only on evidence.

## What never changes on evidence

The retained rules in `DECISIONS.md` (Agile Revival): originality, no reposts, credit is not permission,
rights basis and provenance, conservative data sources, no outreach, no spending without approval, no
deceptive AI imagery, the trademark §5 rule, Account Status monitoring, quality over cadence.
