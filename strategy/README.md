# Strategy

Business context and the recovered strategy research chain.

**Nothing in this directory is an execution plan.** The active experiment state lives in `experiment/`; the
current project state lives in `../PROJECT_STATE.md`.

## What's here

| Path | Status | What it is |
|---|---|---|
| `business/BUSINESS_CONTEXT.md` | **CURRENT** | Consolidated business context, every item status-labelled |
| `historical/CORRECTIONS_LEDGER.md` | **CURRENT** | What each generation of analysis withdrew. **Read before citing anything historical** |
| `historical/STRATEGY_EVOLUTION.md` | Historical | Condensed narrative of the strategy rounds |
| `historical/HISTORICAL_PRICE_MENU.md` | Historical evidence | The 2019–2021 price list. **Not an approved price list** |
| `research/` | Historical | The two recovered research documents — see `research/README.md` |

## Reading order

1. `business/BUSINESS_CONTEXT.md` — what the business is and what is fixed
2. `historical/CORRECTIONS_LEDGER.md` — what has been withdrawn
3. `historical/STRATEGY_EVOLUTION.md` — how the project got here
4. `research/` — only if you need the underlying analysis

## Two standing cautions

**Historical AI analysis is not project policy.** The research documents contain recommendations. A
recommendation became policy only where the founders adopted it into `../DECISIONS.md`.

**Every recovered document is preserved verbatim** — no banners, no edits, no corrections written into the
text. That is why the corrections ledger exists.
