# Strategy Evolution — condensed archive

This file is intentionally an archive, not the active plan.

1. Initial Opus audit correctly identified that the historic repost/low-cost-promo model should not simply restart, but it overclaimed several benchmarks and advertiser/audience inferences.
2. Phase 1+2 research corrected many of those numbers, proposed a controlled revival experiment, and highlighted originality/platform risk. Some claims (especially Hypebeast/category contraction and some originality details) were later corrected.
3. Real Instagram account data was collected for both accounts: Account Status, demographics, geography, 90-day passive behavior, and historical samples.
4. Opus produced a 48-post experiment; ChatGPT identified errors in originality interpretation, follower-liveness inference, content-cell/format confounding, and posting-time confounding.
5. Opus patched the design into a balanced 48-post matrix. ChatGPT then removed performance-based mid-test adaptation to keep the full matrix frozen.
6. Opus confirmed the methodology as fully locked for Week 0.
7. BEFORE LAUNCH, founders deliberately changed cadence to one feed post per day per account. Therefore the 48-post design is now historical methodology reference only. A new balanced 84-post matrix is the next planning task after repository migration.

Do not resurrect discarded assumptions simply because they appear in archived Claude outputs.
